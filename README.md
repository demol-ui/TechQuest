# TechQuest: IT Adventure — v11

This package is prepared for the existing Netlify site **techquestv4**.

## Deploy
Upload the **contents of this folder** as the site publish directory, or use the Netlify CLI from this folder.

The entry point is `index.html` and all referenced assets are in `assets/`.

## Included
- Mobile, tablet, laptop, and desktop responsive UI
- 175 unique catchable creatures across 5 zones
- 12 technology-themed types and type advantages
- Common, Uncommon, Rare, Epic, Legendary, and Mythical rarities
- Creature stats, evolutions, capture, inventory, shop, XP, and battles
- Every attack requires a new IT question
- Zone-specific battle backgrounds
- PWA manifest and service worker
- `.nojekyll` retained for compatibility with static hosts
